# 浏览器验收清单

以下是运行页面中的人工验收步骤，不代表已经执行。自动测试与代码审查不能替代浏览器的真实渲染、点击、焦点和滚动验证。

## 准备

- 更新插件后刷新整个 Harness 页面，打开一份有文字层且有多页的 PDF，以及一份较长的 Markdown。
- 分别通过文档顶部的文字按钮选择「PDF 全文搜索」「Markdown 源文搜索」。
- 为每份文档选一个确定存在、且出现多次的关键词；列表分页检查最好使用超过 40 项的关键词。

## 第 N 项跳转

- 输入合法序号，分别用 Enter 和「跳转」按钮确认；检查当前序号、高亮、PDF 页码一致。
- 输入空白、0、总数 + 1、小数、科学计数法，检查明确报错且不改变选中项。
- 用中文输入法确认输入，检查确认键不会误跳转。
- 手动滚离当前高亮后，重复跳到同一序号，检查能重新定位。

## 上下文列表

- 列表初始折叠；展开后检查匹配上下文、PDF 页码或 Markdown 行号。
- 点击某项，检查正文定位、计数和当前项标记一致。
- 翻到下一批，检查显示范围变化、每批最多 40 项、全文总数不变，且不会仅因翻批次改变选中项。
- 滚到列表底部后换关键词，检查新列表位置重置；上下项导航时，当前条目在列表内可见。
- 检查列表滚动不带动外部聊天区域；窄面板、浅色和深色主题下控件仍可辨认。

## 文档状态

- 文档 A 输入关键词，跳到中间结果，手动翻到另一页或滚动到其他位置；切到 B 做不同搜索，再切回 A。
- 检查 A 恢复自己的关键词、大小写选项、当前匹配、阅读页码、滚动位置和结果列表状态；B 不受影响。
- 切回内置阅读器再切回搜索阅读器，检查同一标签页的搜索状态保留。
- PDF 恢复过程中主动跳到别项或翻页，检查旧恢复任务不会在异步渲染完成后把位置拉回去。
- 在文档变短或结果数量减少后重新加载，检查页码与当前项安全收敛，不出现空白崩溃。
- 关闭标签页再重新打开，以及刷新整个应用后，检查状态按设计重新开始；不承诺跨关闭/刷新持久化。

遇到错误请保留错误文字、插件版本、文件类型与最小复现步骤；不要仅以插件已注册判断功能正常。
