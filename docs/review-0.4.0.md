# 0.4.0 PDF 连续滚动审查

本记录区分代码/自动测试与浏览器实际验收，不把安装成功或阅读器注册等同于真实页面验证。

## 实现范围

- PDF 搜索模式改为按实际视口尺寸排列所有页面，保留全文搜索、高亮和结果导航，删除单页切页控件。
- 全部页有准确占位，canvas/文字层只在视口附近挂载；活跃跳转可临时强制挂载一个远处目标，完成或取消后释放该强制状态。
- PDF.js 的 viewport 数据来自真实页面，包含旋转与页面单位。canvas 与占位使用同一 scale，位图像素数继续受限。
- 源码不导入内置 PDF 私有组件，不修改应用安装文件，不启动替代服务器。

## 主会话与独立复核发现的修正

1. 调整宽度时，新布局可能已把 DOM scrollTop 夹小；锚点改用旧布局下采样接受的位置，而非变化后的临时值。
2. 滚动事件同步记录可接受位置，RAF 仅节流视口发布；清理时取消 RAF/observer/listener，避免切换标签丢最后一帧或泄漏。
3. PDF 页完成/失败通知带渲染代次，避免旧错误状态使新一轮跳转提前完成。
4. 来源、布局宽度、导航 token 与目标页全部匹配才能完成定位；邻页或过时回调不能消费当前意图。
5. 零尺寸隐藏视口不写入错误滚动位置，也不消费导航。恢复可见需要重新建立隐藏期间产生的导航，并重试已经就绪的目标，不能只依赖几何数值改变。
6. 扫描文档提示不占连续布局的正常流高度，避免所有页的纵向坐标偏移。
7. 手动滚动取消待自动定位，不改变当前匹配序号；成功/取消/卸载时清理临时目标及就绪 DOM 引用。

## 自动验证

- 保留原版本搜索、计数、序号跳转、结果列表、文档状态和 Worker 加载测试。
- 新增连续布局、混合纵横页尺寸、远目标按需挂载、布局宽度锚点、全局/页内匹配映射、就绪来源及修订校验测试。
- 主会话独立新增 6 项回归，包括千页布局附近页选择和远目标释放，不模拟 React/DOM。
- 真实两页 PDF.js 提取测试新增原始 viewport 与准确布局断言。
- 独立只读复核发现并确认修复隐藏→可见同几何转换：独立可见性修订同时驱动导航建立和目标页 ready 重发，避免意图永久等待。
- 最终构建、源码/生成 bundle 语法、63 项回归测试和 Git diff 检查通过；独立审查无未解决的阻断项。

## 验证边界

无浏览器控制能力，尚未完成连续滚动的真实页面视觉与交互验收。快速切换、面板 resize、目标页最终高亮与焦点/滚动行为仍需按照 [人工验收清单](manual-checks.md) 检查。新增缩放、OCR、注释、表单和打印不在本次范围。
