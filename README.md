# 专注日历 / Focus Calendar

当前 Harness 的本地插件：`@local/dsh-focus-calendar`。

## 使用

- 左侧导航 → **专注日历**；快捷键 **Alt + Shift + F**。
- 点选日历日期，添加、编辑、勾选完成或删除当天待办。时间字段仅用于排序，不触发待办通知。
- 默认专注 25 分钟，可暂停、继续、重置；完成后手动开始 5 分钟休息。
- 护眼提醒默认每 20 分钟，身体活动默认每 60 分钟，分别手动开启或关闭。
- 「时间设置」支持 1–240 整数分钟，修改对下次启动或下一周期生效。
- 页面内提醒无需授权。「允许系统通知」只在用户点击后申请浏览器权限。
- 所有计时默认关闭。关闭日历面板不停止计时；关闭整个页面则不能显示浏览器通知。

## 数据与限制

数据由 Host storageDomain 的 `focus_calendar` v1 域持久保存，跨会话共享，不上传到外部服务。Host 使用绝对到期时间；睡眠或重启后，每种类型最多保留一条待确认提醒，不连续补发。

准时显示系统通知需要 DSH、网页与电脑保持运行。浏览器后台节流、系统通知权限和免打扰策略可能延迟或隐藏通知。恢复页面后会显示未确认提醒。

这是本地链接安装。**请保留本目录及其 node_modules**；删除或移动目录会破坏当前安装。

## 实现

- `client.js`：原生 Harness 插槽中的 React 日历、待办、计时器、全局提醒。使用宿主主题与中英文 locale，不加载外部 React 或另起页面。
- `index.js`：Host 持久域、鉴权路由、`focus_calendar` 工具及生命周期清理。
- `state.js`：浏览器和工具共享状态机与串行持久化。
- `POST /focus-calendar/api`：先经过当前 Harness Connection 的 Host/Origin/身份校验，再接受 JSON 操作。
- `icon.svg`：本插件原创日历时钟图标，无第三方素材。
