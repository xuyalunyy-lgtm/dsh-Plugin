# 专注日历 / Focus Calendar

DeepSeek Harness 插件：`dsh-focus-calendar`（专注日历）。

包名采用 `dsh-<功能>` 风格。持久化域保持 `focus_calendar`，因此从旧包名 `@local/dsh-focus-calendar` 迁移不改变已有待办和设置。

## 使用

- 左侧导航 → **专注日历**；快捷键 **Alt + Shift + F**。
- 点选日历日期，或用「前一天 / 后一天」「今天」和日期选择器快速跳转；切换月份会将选中日夹到目标月的最后一天（例如 1 月 31 日 → 2 月 28 日）。
- 日历显示每日「完成数 / 总数」，今天有文字标记，选中日期有边框；当天任务区显示完成进度。
- 在列表上方录入待办，按回车添加后可继续输入；中文输入法选词时不提交。时间字段仅用于排序，不触发待办通知。
- 列表默认未完成在前、已完成在后，同组按时间排序；可切换「全部 / 未完成 / 已完成」。
- 点击「编辑 / 改日期」，修改标题、时间或安排日期后保存；移动日期沿用原任务 ID，不改变完成状态。
- 新增草稿按日期、编辑草稿按任务分别保存，不覆盖彼此；退出编辑或切换日期后可再回来继续。Escape 可退出编辑。
- 默认专注 25 分钟，可暂停、继续、重置；完成后手动开始 5 分钟休息。
- 可从未完成待办启动「专注此任务」，记录累计计时和完成轮数；暂停、重置或到期时结算，暂停与休息不计入任务。倒计时完成不会自动勾选任务。
- 提醒可延后 5 或 10 分钟；延后到期再次提示。关闭某类健康提醒会取消该类延后提醒。
- 删除后可立即撤销，或在回收站中恢复；保留 30 天，过期清理。永久删除需要明确确认且不能撤销。
- 展开「备份与恢复」导出 JSON，或选择备份预览后合并／替换导入。替换前自动保留最近一次恢复副本。
- 护眼提醒默认每 20 分钟，身体活动默认每 60 分钟，分别手动开启或关闭。
- 「时间设置」支持 1–240 整数分钟，修改对下次启动或下一周期生效。
- 页面内提醒无需授权。「允许系统通知」只在用户点击后申请浏览器权限。
- 所有计时默认关闭。关闭日历面板不停止计时；关闭整个页面则不能显示浏览器通知。

## 数据与限制

数据由 Host storageDomain 的 `focus_calendar` v1 域持久保存，跨会话共享，不上传到外部服务。Host 使用绝对到期时间；睡眠或重启后，每种类型最多保留一条待确认提醒，不连续补发。

准时显示系统通知需要 DSH、网页与电脑保持运行。浏览器后台节流、系统通知权限和免打扰策略可能延迟或隐藏通知。恢复页面后会显示未确认提醒。

未提交草稿单独存储在当前浏览器标签页的 `sessionStorage`，支持同标签页内切日期、关闭面板和刷新恢复，不作为跨设备备份，也不保证关闭标签页后保留。浏览器存储不可用时降级为内存并显示提示。删除任务也会清除该任务的编辑草稿。

保存过程中请尽量不要刷新整页；如果网络中断导致结果不明确，先检查列表再重试，避免重复新增。插件不能保证网络中断或整页刷新后的新增恰好执行一次。

当前开发设备是本地链接安装。**请保留本目录及其 node_modules**；删除或移动目录会破坏当前安装。迁移时可使用包含 Zod 依赖的 `.tgz` 安装包，不依赖此源码目录的位置。

## 备份与迁移

- 备份格式：`format=dsh-focus-calendar`、`version=1`，包含导出时间、已保存任务及专注统计、时间设置、回收站；不包含浏览器草稿、运行中计时或系统通知授权。
- 导入先预览，再用绑定备份内容与本机数据的 token 确认；数据改变后旧预览会失效。
- 合并按 ID 保留本机同 ID 项和设置，仅加入新 ID；替换恢复备份中的数据，同时自动保存一份替换前恢复副本。
- 两种模式均停止计时／提醒、清除待提示与延后提醒。导入错误不会写入部分数据。
- 文件上限 4 MiB，HTTP 封装请求上限 5 MiB。每个活动任务／回收站集合最多 2000 项。
- 数据备份与发布物放在 Git 忽略的 `artifacts/`，不把个人安排提交到源码仓库。
- 换设备步骤见 [RESTORE.md](./RESTORE.md)。**代码仓库不是个人数据备份**，请将安装包和最新导出的 JSON 另存至可信位置。

## 实现

- `client.js`：原生 Harness 插槽中的 React 日历、待办、计时器、全局提醒。使用宿主主题与中英文 locale，不加载外部 React 或另起页面。
- `index.js`：Host 持久域、鉴权路由、`focus_calendar` 工具及生命周期清理。
- `state.js`：浏览器和工具共享状态机与串行持久化。
- `POST /focus-calendar/api`：先经过当前 Harness Connection 的 Host/Origin/身份校验，再接受 JSON 操作。
- `icon.svg`：本插件原创日历时钟图标，无第三方素材。
