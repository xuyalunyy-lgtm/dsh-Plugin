# Codex 管理中心

专注管理当前 DSH profile 已安装的 `dsh-llm-codex` 连接。**不注册任何模型路由**，沿用现有 `codex` provider。当前适配器、登录文件、默认模型和其他插件均保持原有所有权。

## 使用

安装后刷新当前 DSH 页面，打开 **设置 → Codex 管理中心**。

页面以额度概览为首要信息，连接状态紧凑显示；接入设置保留代理和 Fast，协议版本与超时收纳在高级设置。模型目录、文本测试和诊断报告可分别展开。折叠或展开不会触发请求；Fast 的开关修改仍须点击“保存设置”才生效。界面沿用 DSH 主题色并适配窄屏。

- 每次打开管理页面时先读取本地连接状态；适配器已启用且发现凭证后，自动查询一次账号额度。页面停留、额度倒计时、手动刷新状态或保存配置不会触发重复自动查询；关闭页面会中止本页请求。首次失败后不自动重试，可点击“手动刷新额度”。存在凭证并不意味着令牌有效。
- **刷新账号额度**只读查询 ChatGPT Codex 的额度接口，显示剩余百分比、服务端实际周期、重置时间和查询时间；不是准确剩余 Token 数。不轮询、不发模型生成请求、不刷新或改写登录凭证。API Key 模式明确显示不支持；接口缺失或失败不会显示伪造的 0%/100%，也不影响聊天。刷新失败会清空旧额度，避免过期数据误导。此接口可能随服务端变化。
- **额度提示**在页面内显示距查询和距重置的相对时间，每 30 秒只更新本地显示，不发网络请求。默认 10 分钟后标记历史数据，可调整为 1–120 分钟；默认剩余不高于 20% 时提示，可设 0–100%，0 关闭。仅新鲜且未到重置时间的有效数值触发低额提示；到重置时间后要求手动刷新，绝不自动置为 100%。偏好仅当前页面有效，不改 Host 设置。
- **诊断报告**仅手动生成，可预览并复制 JSON。生成只读本地状态，不查询额度或发送模型请求；只含插件/适配器版本、认证模式、代理是否显式配置（不含地址）、客户端版本/超时，以及本 Host 插件生命周期最近一次测试/额度/错误码的安全快照。不包含模型生成文本、自由格式异常、邮箱、账号标识、Token、模型 ID 或私人路径；不自动上传。配置变化后清除旧操作快照，重启清空记录。
- **使用与排错**在页面底部折叠显示：凭证/目录/额度的含义、设置用途、常见失败与卸载行为。
- **刷新模型目录**读取适配器目录与缓存，显示模型 ID、文本/图片模态、上下文与推理等级。目录声明不代表真实请求成功。
- **Fast：申请优先处理**默认关闭。勾选并保存后，当前 profile 的全局 Codex 适配器后续请求申请 `service_tier: "priority"`；可能消耗更多额度，是否支持由模型和账号决定，不保证加速，也不等于推理等级。不支持时不会静默重试降级。升级本版与支持 `fastMode` 的适配器后需重启 DSH，旧 Host 模块缓存可能仍不支持该参数；保存成功不证明实际服务等级已生效。未主动保存开启不会改变现有账号配置。
- **Fast 工具兼容**：`saveSettings.settings.fastMode` 为可选布尔；省略时保留适配器原值（包括保持未配置），`status` 对未配置返回有效默认值 `false`。明确 `true`/`false` 才设置该值；其余三个设置仍必填。诊断报告的 `connection.fastMode` 仅表示已配置偏好，`fastModeMeaning` 明确不代表实际返回的服务等级；无法读取配置时不推断已开启。
- **保存配置**只改当前适配器的代理、协议客户端版本、流空闲超时及可选 Fast 设置，保留 `authFile`、`writeBack` 等其他设置。编辑版本冲突拒绝覆盖，保留页面草稿。代理只接受无用户名密码的 HTTP(S) 地址；空字符串沿用适配器环境代理。
- **测试连接**仅给所选目录模型发送固定的短文本，不发送当前会话和工具。此操作消耗账号配额，45 秒超时；不会自动执行，不轮询，不自动重试。真实请求可能触发现有适配器的令牌刷新及其既有写回规则。
- 本版支持展示现有适配器的文字与图片理解能力，不声称支持音频、视频、图片生成，也不重新实现多模态传输。

必须先通过 Codex CLI/桌面端登录。管理中心不处理 OAuth、退出、令牌删除或账户切换，不启动 CLI，不修改共享凭证文件。

## 范围与隐私

Host 用 `configEditor` 保存适配器设置，避免手工编辑 profile 文件。界面和 `codex_manager` 工具调用同一组操作。接口经 DSH 连接鉴权，限制 8 KiB JSON。凭证、原始异常、账户 ID 与凭证路径不返回浏览器或工具。模型测试结果只包含成功状态、耗时、固定错误类别及用量，不返回模型生成文本。

没有额度后台轮询、自动切换模型、默认模型编辑、会话迁移、子代理管理、网络端点编辑或多账户功能。卸载只移除管理界面和接口，不卸载或禁用模型适配器。经管理中心保存的连接设置仍保留在原适配器上。

Fast 到 priority 的协议依据：[OpenAI Codex 固定版本配置类型](https://raw.githubusercontent.com/openai/codex/a3697361dfc0bc438b65ae8a9aa0e598ecd45251/codex-rs/protocol/src/config_types.rs)。管理中心只保存布尔偏好，请求映射由独立适配器负责。

## 开发与验证

纯 ESM JavaScript，Client 从 DSH 模块表读取 React，零新增 npm 依赖、零安装脚本。Host 使用当前安装提供的服务；不导入另一份 Harness 类。

```powershell
node --test test/*.test.mjs
node --check client.js
```

测试覆盖配置冲突、保留其他设置、凭证脱敏、固定文本测试、鉴权前置、请求大小、无副作用操作范围与卸载清理。安装后还需验证真实 Host 接口和 Client 插槽。目录/文本测试不构成图片理解的端到端测试。
