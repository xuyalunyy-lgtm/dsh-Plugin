# 会话管理 / Session Manager

当前 DSH Web GUI 的会话管理插件，入口为左侧导航中的 **会话管理**。

## 永久删除：宿主依赖与验证边界

工作区候选增加 `purge`，与旧 `delete` 的可恢复归档语义分开。已归档列表提供独立确认；需要配套 Desktop 宿主补丁提供 `workspaceRegistry.purgeArchivedSession`。未安装补丁时拒绝操作，不直接删除日志文件。目标限定为已归档且无活动任务的会话；已加载会话的正常释放及关联检查由配套宿主负责，插件不会自行强制停止任务。

永久删除会移除目标原始日志及搜索记录，不能恢复；不删除项目文件或其他会话中的历史副本。请求冻结 `expectedToken` 和 `expectedStorageRevision`，不确定结果只重试原 `requestId`。当前完成插件侧候选及 47 项隔离/回归检查（含 5 项永久删除请求测试：无宿主支持、删除后响应丢失、并发同请求、归档前置条件、明确未提交拒绝）。测试中的宿主删除使用替身，仅证明插件协议行为。本轮已在当前本机宿主实现中核对到同形公开接口及空闲会话正常释放逻辑，但未执行真实永久删除全链路；该本机实现不代表官方 `0.2.2-rc.1` 均提供此能力，也不属于本插件包交付内容。

## 功能

- 按工作区筛选会话；搜索标题、会话 ID 和目录；分页查看。
- 工作区眼睛按钮：点击隐藏/显示，状态持久保存；会话管理页和独立侧栏共用设置，管理页支持临时勾选“显示已隐藏的会话”。
- 独立侧栏浏览器：VS Code 风格的分组列表、展开/折叠、标题/ID 筛选、运行提示、隐藏恢复和打开会话；保留原生侧栏外壳。
- 在指定工作区新建会话。
- 把历史迁移到另一个已注册工作区，在目标工作区继续聊天。
- 明确的 **归档** 与 **恢复**：管理页、独立侧栏均可操作；归档保留历史，不永久擦除。旧删除接口仍保持可恢复归档的兼容行为。
- 多选本页会话、全选本页及选择本页空会话，确认后批量归档并逐项展示结果。
- UI 和智能体工具 `session_manager` 使用同一组 Host 操作；修改前检查版本，重复请求使用相同凭证。

## 多选删除空会话（v1.3.0）

1. 在活动会话列表勾选左侧复选框；或点击 **全选本页** / **选择本页空会话**。
2. 点击 **删除所选**，核对确认框中的会话数量、标题和 ID 后确认。
3. 操作逐项执行：成功项归档，运行中、状态冲突或不可读取项保留并报告原因。需要再次处理失败项时，刷新后重新勾选。

- 只选择当前页的可操作会话，不会暗中处理其他分页、隐藏筛选或搜索范围之外的会话。切换筛选、翻页、刷新会清空选择。
- “空会话”以实际记录判断，不依赖“新会话”标题；包含消息、工具调用、目标、团队、子智能体或未知内容的记录不会被当作空会话。初始配置、标题等不算对话内容。即使自动选择为空，仍须人工确认。
- 批量删除仍为可恢复归档，不会清理磁盘或永久擦除。后台会逐项重新校验状态，不自动强制停止任务。
- 结果未确认时只使用 **重试原请求**，不要重新另建批量请求；重试不会再次归档已成功后又恢复的会话。

## 工作区隐藏 / 显示

页面顶部 **工作区可见性** 区域列出全部已注册工作区。点击工作区右侧的眼睛按钮切换：睁眼为显示，划线眼睛为隐藏。隐藏后，默认会话列表、搜索及工作区筛选不再显示其会话；该区域仍保留这个工作区，方便再次点击恢复。

- 勾选 **显示已隐藏的会话** 可临时查看所有隐藏工作区的会话，不修改其保存状态。
- 新建和迁移目标默认不列已隐藏工作区；需要时先点击眼睛恢复显示。
- 隐藏设置作用于会话管理页及启用的独立侧栏浏览器，不修改 DSH 原生侧栏的数据或排序，不影响文件、会话归档、访问权限或任何任务运行。恢复原生浏览器后，原生列表不应用此过滤；隐藏不是访问控制或隐私隔离。
- 设置由 Host 持久化，在本机同一配置的不同会话/浏览器共享，通过鉴权事件流同步已提交版本。版本冲突会拒绝覆盖，请核对最新状态后再次点击。
- 可见性请求绝对赋值并带唯一凭证；重试旧请求不会把新设置再翻转。待确认操作沿用页面的“重试原请求”入口。

## 独立侧栏浏览器

首次使用默认保留原生列表。在会话管理页勾选 **使用独立侧栏浏览器** 后，会保存此客户端的选择，刷新或重启后自动恢复。独立浏览器只替换 `sidebar.workspaces` 内容，不复制原生组件、子插槽、注入逻辑或排序 store。品牌、折叠按钮、导航入口和底部设置仍由 DSH 渲染。

- 点击工作区标题展开/折叠，工具栏支持全部展开/折叠。工作区按宿主顺序显示；会话中当前空白项、置顶项优先，其余按更新时间排列。不写入或继承原生手动排序。
- 筛选涵盖工作区名称/路径、全部可见会话的标题和 ID，不受折叠状态限制，不搜索消息正文。活动视图不列归档和顶层子智能体，非当前的空白会话也不列出。切换 **已归档会话** 可查看归档记录（包括空会话），点击会话行右侧恢复按钮，核对后恢复。
- 工作区右侧眼睛用于隐藏；底部 **已隐藏的工作区** 保留恢复按钮，不受筛选词影响。默认工作区按正常工作区处理；“未分组”不是真实工作区，第一版只支持折叠，不支持持久隐藏。
- 隐藏当前工作区不会切换聊天、停止任务或释放当前会话。点会话使用宿主导航接口，归档会话不会隐式恢复。
- 每个真实工作区标题右侧的 **新建会话** 按钮（对话框加号图标）在该工作区创建独立空白会话并打开，不会误用当前聊天的其他工作区，也不复用旧空白会话。与管理页共用请求凭证和写入锁；结果不确定时只允许重试原请求。创建已成功但导航失败时，用 **打开新会话** 再次导航，不需要重复创建。“未分组”没有可创建的目标工作区，不显示此按钮。
- 标题栏 **添加工作区** 按钮（文件夹加号图标，折叠侧栏也有入口）打开宿主原生目录选择器，将选中的已有目录注册为工作区；取消不会创建，不自动新建或切换当前会话。重复选择已有目录由宿主幂等处理；若对应工作区已隐藏，会提示从隐藏列表恢复，不擅自更改隐藏设置。
- 侧栏与管理页统一使用原创线性 SVG 图标和 DSH 主题色：搜索支持一键清除，当前会话使用品牌色高亮，运行/等待/未读完成状态分别以圆点或菱形提示。工作区操作按钮保留键盘焦点和文字标签，动画遵循系统减少动态效果偏好。
- **打开会话管理** 可执行新建、迁移、归档等已有操作。第一版不提供侧栏拖拽、原生右键菜单、工作区重命名及原生工作区搜索快捷键；需要原生操作时先恢复原生列表。当前添加入口依赖宿主原生目录选择器；无可用选择器时显示错误，不绕过宿主权限。
- 管理页的 **使用独立侧栏浏览器** 开关可即时启用或恢复原生列表。选择保存于当前浏览器/桌面客户端的 localStorage，刷新或正常重启后恢复；不同浏览器或 Web 地址来源不共享。无法读写客户端存储时显示错误，不伪称已经保存。停用整个插件同样释放注册项。
- 同步或延迟注册失败均显示管理页错误并保留原生列表，不向启动过程抛出注册异常；不会自动换优先级或循环重试。可取消勾选以保存关闭状态，或排除冲突后再次明确启用。
- 首次显示前等待隐藏设置基线及宿主目录就绪；短暂断线保留上次成功加载的列表和隐藏设置，并显示重连提示，恢复连接前禁用修改，不再把加载/断线误判为空工作区。所有工作区都被隐藏时明确提示，并自动展开底部恢复入口，不擅自清除隐藏设置。若自定义组件渲染错误，宿主可能回退显示原生内容，因此隐藏不能用作权限隔离。
- 每条会话右侧的 **归档** 按钮会先读取版本凭证，再显示确认框；归档与恢复都通过共享 Host 操作和幂等凭证执行。运行中、后台活动或版本变化会被拒绝，不会自动停止任务。归档会取消置顶。

## 移动的含义与边界

当前 DSH 没有修改原生会话所属工作区的公开接口，原始工作区信息不可变。因此本插件采用经用户确认的安全迁移方案：

1. 校验源会话、目标工作区、活动状态与读取版本。
2. 临时归档源会话，阻止新的模型步骤进入，然后复查历史快照。
3. 在目标工作区建立 **新 ID** 的会话，承接历史并把有效执行目录设为目标目录。
4. 新会话持久化并关联目标工作区后，源会话保持归档，作为恢复依据。
5. 发生失败时尽量恢复源会话；结果不确定时保留原请求凭证，只能用同一请求重试。

迁移不是复制项目文件：旧消息、工具结果、绝对路径、附件引用仍保留原意。继续操作前应核对原目录引用。不能原地保留会话 ID。

### 含目标、提醒、团队或子智能体记录的会话

v1.2.0 不再因为历史中出现这些记录就拒绝迁移。源事件、序号、消息、工具结果及附件引用完整保留，按 DSH 原生 fork 的继承切点建立独立会话：

- **目标**：目标状态和历史保留；新会话的自动继续默认未启用，需要用户明确恢复。
- **提醒**：历史记录保留；Host 提醒仍绑定原会话，不会复制成新的提醒。仍有效的提醒属于实际活动，需要先处理后才能归档/迁移。
- **团队、子智能体**：旧成员、任务和目录事实作为历史保留，不转交给新会话；新会话不会获得操控旧成员的权限。需重新组织的工作应在新会话明确创建。
- **工作流**：执行记录保留，但不会因为读取历史而重新运行。
- **仍会阻止迁移**：原会话/实际后代运行中、正在创建子智能体、后台任务、排队输入或未闭合轮次/工具调用，以及源本身是子智能体会话。

若仍提示“正在运行”或“排队输入”，先回原会话完成/停止对应活动，刷新列表后重试。插件不会为解除保护自动停止任务，也不会删除关联历史。

## 删除与恢复

“删除”是 DSH 原生归档，不是永久擦除：不会清理磁盘日志，不提供隐私擦除保证，也没有自动到期清理。归档会移除置顶；恢复回到原工作区，不恢复原来的置顶和已停止工作。运行中或存在后台活动的会话应先结束任务，再操作。

## 使用

1. 打开左侧 **会话管理**；若安装后尚未出现，请刷新当前 DSH 页面。
2. **新建会话**：选择工作区，确认后点击“打开新会话”。
3. **移动**：点击对应会话的“移动”，选择目标工作区，确认迁移。
4. **归档**：在管理页或独立侧栏点击归档并确认；切到 **已归档会话** 点击“恢复”。旧的删除和批量删除仍是可恢复归档，不是永久删除。
5. 若提示请求结果未确认，使用 **重试原请求**。不要关闭当前标签页或另造请求来重复迁移。

未确认操作凭证保存在当前标签页的 sessionStorage 中；关闭标签页、换浏览器或设备不会携带该凭证。新建与迁移不会自行发起模型请求。Host 端成功/恢复凭证永久保留，最多 4096 条，满后拒绝新的修改请求，不会通过自动清理牺牲防重复保证。

插件内的修改串行执行并校验读取版本；DSH 原生操作没有跨插件原子锁。迁移期间请勿在其他标签页打开目标副本或对源会话做恢复、重命名等修改。并发变化会尽量检测并取消迁移，但不能将其当成跨进程事务。

## v1.5.0 修复与归档（2026-11-05）

- 修复独立侧栏将临时 SSE / 工作区目录重连误判为无可见工作区的问题；保留最后成功列表，连接恢复前禁用修改。
- 增加侧栏和管理页的明确归档操作、已归档列表及恢复确认。
- 适配当前 DSH `0.2.2-rc.1`：旧 `sessionController.inspect()` 已不存在。活动会话通过公开 `sessionQuery.observeSession()` 捕获并释放只读观察；冷会话通过持久化只读句柄读取并关闭，保留原始未闭合事件，不使用会自动补齐结束事件的冷查询结果，也不恢复或激活会话。
- 已有 42 项测试通过；在运行实例用新建空白会话实测归档和恢复，验证后将该验证会话留在归档中。未更改原有会话或隐藏设置。无浏览器控制，断线重连视觉表现和按钮排版仍需刷新当前 GUI 后核对。

## v1.5.1 状态与恢复修复（2026-11-05）

- 独立侧栏参考原生状态优先级：待审批 / 计划审阅 / 回答优先于自身或子智能体运行，再到未读完成和空闲。使用宿主橙、蓝、绿、灰主题色及文字提示；已完成提示是未读完成提醒，不是手工待办状态。
- 同一筛选刷新保留列表，不同筛选或工作区可见性版本切换先显示占位并禁止对旧行写入；拆分排序和筛选，减少重复列表请求。
- 迁移恢复按不可变头部字段及规范化后的 `delegationDepth` 比较，不再因 JSON 字段顺序或宿主默认值误判自己的目标副本已被修改。
- 本轮现有检查与 42 项测试通过，夹具已改为持久化只读 / 活动观察合同，并模拟宿主头部规范化；未新增真实会话或执行真实迁移。状态颜色和文字已由用户刷新当前 GUI 后确认正常，最新后端修复仍需正常重启 DSH 后加载。

## 启动故障修复（2026-11-04）

本地 1.4.0 草稿曾包装 `sidebar.workspaces` 并重复声明原生工作区浏览器已拥有的子插槽，触发 DSH 客户端注册失败及 `web boot: 1 entry did not activate`。该包装方式已移除。当前独立浏览器仅注册自己的区域组件，不声明或复制原生子插槽；原生组件及其注册保持存在，退出独立浏览器时可重新显示。修复及独立浏览器均不删除会话、归档或插件持久化数据。

随后独立浏览器初版还曾遗漏显式优先级：已安装静态客户端插件不经过动态插件的自动优先级分配，默认 `0` 与原生浏览器冲突。现改为显式 `priority: -1`（数值较小者显示）；首次仍需在管理页明确启用，后续按已保存的客户端偏好自动恢复。注册错误由插件捕获并在管理页呈现，保留原生列表。

若此前已将插件停用，应在插件管理器中重新启用本插件，然后正常重启 / 刷新原有 GUI。已安装为目录链接时会读取链接目标的修复代码，但不能据此认定当前已打开的页面已重新加载成功。

## 开发与安装

插件使用普通 JavaScript，无需构建，不执行安装脚本。运行时依赖清单中声明的 Zod；本地目录开发先在本插件目录安装依赖，再通过插件管理器安装，避免链接目录缺少依赖。页面没有 CDN、远程图片或字体。

```powershell
node --check index.js
node --check controller.js
node --check client.js
node --test
```

通过 DSH `plugin_manager` 安装本目录。不要手写配置目录或移动底层会话文件。首次安装后以工具结果 `application` 判断是否已应用；替换已安装的 Host 模块可能需要重启 DSH。

`icon.svg` 为本插件原创图标；无第三方图片、字体或网络依赖。页面使用 Host 主题变量，支持中英文随 DSH 语言切换。
