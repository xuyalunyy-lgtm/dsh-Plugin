## 已知非阻塞限制

- 同一仓库的外部 Git 进程不受插件互斥锁控制，多次读取不是原子快照；实际写入仍重新验证。
- 旧总览批次失效但请求尚未结束时，刷新点击可能暂时不执行；等原请求结束后可再次刷新。两个 worker 的并发上限是单面板维度，服务端另有全局请求预算。
- 分支标签重复点击可能触发多次只读请求及 429；旧响应会被丢弃。symbolic 分支别名标记未专门展示，但真实删除会被服务端拒绝。
- 操作记录只存当前宿主进程内存；重启会清空。极端日志 finish 异常会保留 running 槽位，需要重启恢复，不能据此推断实际 Git 操作未发生。
- 当前仓库记录筛选在最近 100 条会话记录中进行，不代表该仓库所有历史。
- 客户端测试使用轻量 React hook 模拟，不替代真实 GUI 的视觉、键盘与窄面板验收。必须重启 DSH 并刷新现有 GUI 后人工检查。

## 本机发布方式

此包的客户端本身是预构建 ModuleLoader 脚本，无额外 Web 构建依赖。发布需要将包清单内文件同步到桌面 profile 安装副本，备份旧版并逐文件比较 SHA-256；宿主重启后才加载新版，不承诺 HMR。安装路径与使用方式见 [README](README.md)。
